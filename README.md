> **Computer Vision & Autonomous Infrastructure Safety System** for classifying road surface defects (potholes, severe cracks, debris) and scoring road repair urgency using computer vision telemetry metrics.

---

## 🌟 Key Highlights
- **Accuracy**: 98.44% weighted test accuracy across 4 road surface condition classes.
- **Urgency Scoring**: Automated depth-area weighted prioritization index for municipal road maintenance.
- **Interactive UI**: Real-time Streamlit diagnostic simulator with confidence probability distributions.
- **Author**: **[Arjuna Fransesco](https://github.com/ArjunaFransesco)**

## 🚀 Quickstart Guide

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/ArjunaFransesco/yolov8-road-hazard-safety-detector.git
cd yolov8-road-hazard-safety-detector
pip install -r requirements.txt
```

### 2. Run Interactive Web Dashboard
```bash
streamlit run app.py
```

### 3. Open Jupyter Notebook
```bash
jupyter notebook notebooks/road_hazard_detection_cv.ipynb
```
